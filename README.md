# DAYFLOW

로컬 PC에서 할 일, 일정, 알림장과 메모를 관리하는 개인용 웹앱입니다. 데이터는 외부 서버가 아닌 이 폴더의 SQLite 데이터베이스에 저장됩니다.

## 실행

Windows에서 `DAYFLOW 실행.cmd`를 두 번 클릭하세요. Node.js 22.15 이상이 필요합니다. Node.js가 없다면 https://nodejs.org/ 에서 먼저 설치하세요. 첫 실행에 의존성이 없다면 인터넷 연결을 통해 설치합니다. 브라우저에서 http://127.0.0.1:5173 에 접속합니다. 서버 창을 닫으면 종료됩니다. 이미 실행 중이면 주소로 바로 접속하세요.

직접 실행하려면 Node.js 22.15 이상에서 `npm install`, `npm run dev`를 실행합니다. 프론트엔드는 5173, API는 3001 포트를 사용하며 localhost에만 바인딩합니다. `npm run build`로 프론트엔드 빌드, `npm test`로 API 검증을 실행합니다.

## 저장 및 기능

DB는 `data/dayflow.sqlite`에 최초 실행 시 자동 생성됩니다. 앱 종료와 재시작은 기존 데이터를 보존합니다. 사이드바의 백업은 JSON 파일을 내려받으며, 복원은 현재 데이터를 백업 파일 내용으로 교체합니다. 중요한 데이터는 복원 전 먼저 백업하세요.

오늘 할 일 빠른 입력·완료·수정·삭제, 날짜 지정, 월간 캘린더와 시간 일정, 날짜별 목록, 알림장 중요 고정·확인, 메모, 검색, 백업·복원을 제공합니다. 일정은 로컬 시간으로 입력하며 저장 시 시간대 오프셋을 포함합니다. 알림 발송, 반복 일정, 프로젝트 분류, 주간·일간 보기, 통계, AI 및 외부 캘린더 연동은 구현하지 않았습니다.

## 확인 방법

오늘 할 일을 Enter로 입력하고 완료·복원하세요. 캘린더에서 날짜를 선택해 일정을 추가한 뒤 수정해 보세요. 알림장에 중요한 공지를 작성하고 확인 상태를 변경하세요. 새로고침 또는 서버를 다시 시작한 뒤 내용이 유지되는지 확인할 수 있습니다.

## AI와 대화

사이드바의 **AI와 대화**에서 자연어로 알림을 설명하세요. 제안된 제목·내용·날짜를 검토하고 저장하면 알림장에 추가됩니다. 대화는 화면을 떠나면 초기화되며, 입력한 대화는 응답을 위해 OpenAI로 전송됩니다. Codex CLI의 ChatGPT 로그인을 사용하므로 별도의 API 키는 필요하지 않습니다. 사용 중인 계정의 Codex 사용 한도와 네트워크 상태에 따라 응답이 제한될 수 있습니다.

이 PC의 Codex CLI를 자동으로 찾습니다. CLI가 없거나 로그인되어 있지 않으면 설치 및 `codex login`이 필요합니다. 다른 위치에 설치된 경우 서버 실행 전에 `DAYFLOW_CODEX_PATH` 환경 변수에 실행 파일 경로를 지정할 수 있습니다. 변경 사항을 적용하려면 기존 서버를 종료하고 다시 실행하세요.
